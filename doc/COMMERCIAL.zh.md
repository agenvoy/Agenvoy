> <a href="../COMMERCIAL.md">English</a> · <strong>繁體中文</strong>

Agenvoy 採雙授權。本頁說明商業授權；開源授權請見 [LICENSE](../LICENSE)。

**任何商業授權需求，請直接聯繫開發者 `dev@pardn.io`** —— 沒有經銷商、沒有表單、沒有公開價目表，條款逐案議定。

## 你適用哪一種

| 你的情境 | 授權 |
|---|---|
| 個人使用、研究、評估 | AGPL-3.0 — 無須任何動作 |
| 內部工具，不透過網路提供給使用者 | AGPL-3.0 — 無須任何動作 |
| 衍生作品以 AGPL-3.0 釋出並附上原始碼 | AGPL-3.0 — 無須任何動作 |
| 將 Agenvoy 或其衍生作品透過網路提供給使用者，且不公開自身原始碼 | **商業授權** |
| 將 Agenvoy 嵌入所散布的專有產品 | **商業授權** |
| 組織政策禁止交付產品中含有 AGPL 元件 | **商業授權** |

判準是 AGPL-3.0 §13：若使用者透過網路與修改後的版本互動，該版本的完整原始碼必須提供給這些使用者。商業授權免除此義務。

## 商業授權授予什麼

- 使用、修改與散布 Agenvoy，不受 AGPL-3.0 原始碼公開義務約束
- 嵌入閉源產品與託管服務
- 自行的修改可不公開

不轉移著作權，也不限制任何人使用 AGPL-3.0 版本。

## 不包含的部分

商業授權只授予軟體本身的使用權利，不包含開發者的任何工時。

**任何委由開發者進行、與本專案有關的改動，一律與授權費用分開報價、另行計價** —— 客製功能、既有行為的調整、依你方時程處理的 bug 修正、整合、部署、移轉、版本升級、維護、支援承諾或 SLA、教育訓練，各自屬獨立委託，各自議定與計價。

持有商業授權不代表需求會被優先處理，也不構成開發者承接的義務。

請直接聯繫開發者 —— 維護者暨唯一著作權人 [邱敬幃 Pardn Chiu](https://www.linkedin.com/in/pardnchiu)。來信 `dev@pardn.io`，並提供：

## 第三方元件

Agenvoy 依賴外部模組 —— `go-llm-router`、`go-pkg`、`go-bot`、`go-browser`、`go-scheduler`、`go-sqlkit`、官方 MCP go-sdk，以及 `go.mod` 內列出的其餘項目 —— 各自有自己的授權。Agenvoy 的商業授權只涵蓋 Agenvoy 本身，依賴套件仍依其原授權條款。
