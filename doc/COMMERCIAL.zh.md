Agenvoy 採雙授權。本頁說明商業授權；開源授權請見 [LICENSE](../LICENSE)。

## 你適用哪一種

| 你的情境 | 授權 |
|---|---|
| 個人使用、研究、評估 | AGPL-3.0 — 無須任何動作 |
| 內部工具，不透過網路提供給使用者 | AGPL-3.0 — 無須任何動作 |
| 衍生作品以 AGPL-3.0 釋出並附上原始碼 | AGPL-3.0 — 無須任何動作 |
| 將 Agenvoy 或其衍生作品透過網路提供給使用者，且不公開自身原始碼 | **商業授權** |
| 將 Agenvoy 嵌入所散布的專有產品 | **商業授權** |
| 組織政策禁止交付產品中含有 AGPL 元件 | **商業授權** |

判準是 AGPL-3.0 §13：若使用者透過網路與修改後的版本互動，該版本的完整原始碼必須提供給這些使用者。商業授權免除此義務。

## 商業授權授予什麼

- 使用、修改與散布 Agenvoy，不受 AGPL-3.0 原始碼公開義務約束
- 嵌入閉源產品與託管服務
- 自行的修改可不公開

不轉移著作權，也不限制任何人使用 AGPL-3.0 版本。

## 條款

價格與條款依部署規模與散布模式逐案議定，無公開價目表。

## 聯絡方式

來信 `dev@pardn.io`，並提供：

- 貴組織名稱
- Agenvoy 的部署方式（託管服務、地端、嵌入所散布的產品）
- 概略規模（席次、執行個體數或終端使用者數）
- 預計時程

## 貢獻

貢獻一律以 AGPL-3.0 授權。送出 pull request 即表示同意維護者得同時以商業授權散布該貢獻，使上述雙授權得以持續成立。
